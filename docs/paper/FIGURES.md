# Figure and table plan

Every figure is generated by a script in `docs/paper/figures/` reading the
experiment store or committed measurement records — no hand-drawn data.
Style: matplotlib, colorblind-safe, one message per figure, caption states
the takeaway.

## Figures

**F1 — Pipeline with trust boundaries** (§3, full width)
Block diagram: workload manifest → capture → ranking → specgen → sandboxed
search → independent validation → artifact bundle → dispatch → paired A/B →
finalize. Annotate: (a) the write boundary around the search sandbox,
(b) the hash-verification points, (c) terminal states (promoted /
quarantined / rejected / no_worthwhile_candidate / invalid). Source:
drawn (TikZ or draw.io→PDF), reviewed against optimize.py stage names.

**F2 — The dispatch tax, before and after** (§5)
Per-call waterfall for the LTX transformer artifact: kernel saving
(124 µs) vs delivery costs (parameter snapshots, placeholder rediscovery,
eager FX replay = 3.104 ms), then the post-fix bar from the sm100
measurement records. Log-scale inset: per-generation totals (1.192 s,
32.4% of e2e). Source: R4 §3 numbers + docs/dispatch-overhead/*.json.

**F3 — Break-even curve** (§5)
Overhead per call vs calls-per-generation: iso-lines for net-zero at given
kernel savings; plot VAE (4.7 calls, 0.39%) and transformer (384 calls,
32.4%) as points. Message: identical artifacts, opposite economics.
Source: autokernel/dispatch break-even data + R4 table.
